# 03. 부품 조사와 선정

작성: 길선영 · 2026-10-24 ~ 2026-11-02

## 1. 부품별 선택 이유

| 구분 | 선택 | 선택 이유 | 조건과 주의 |
|---|---|---|---|
| MCU | ESP32-S3-DevKitC-1 (N16R8 또는 N8R8) | 레퍼런스의 Arduino Nano는 RAM이 2KB 수준이라 고속 로깅 버퍼를 두기 어렵다. PSRAM으로 SD 기록 지연을 흡수하고, 와이파이·BLE가 내장되어 있다. | GPIO 35~37은 PSRAM이 쓰므로 사용하지 않는다. 예비 1개를 함께 구매한다. |
| IMU | ICM-42688-P (SPI 브레이크아웃) | 가속도 ±16g와 자이로를 함께, 높은 샘플링으로 기록한다. | 3.3V 전용. 400Hz로 시작해 데이터 품질과 저장 용량을 보며 조정한다. |
| GPS | u-blox M10 계열 (SAM-M10Q 등) | 위치·속도·시간 제공, 갱신률 설정 가능, 저전력. | 위성 조합에 따라 최대 갱신률이 달라지므로 설정별로 실측한다. |
| 저장 | 3.3V SPI microSD 모듈 + 32GB 이하 카드 | 분석·학습용 원본 데이터를 보존한다. | FAT32, 블록 단위 버퍼 저장. |
| 전원 | 1차: USB 보조배터리 / 최종: 충전·승압 모듈 + 보호회로 배터리 | 1차는 전원 변수를 없애 로거 검증에 집중한다. | 일부 보조배터리는 저전류에서 자동 차단되므로 확인한다. |
| 동기화 | 방수 모멘터리 버튼 | 정지 상태에서 누른 순간을 로그와 영상에 함께 남겨 시간을 맞춘다. | 주행 중에는 누르지 않는다. |
| 영상 촬영 | 스마트폰 + 핸들 거치대 | 정답 라벨을 영상과 기록 시간을 맞춰 사후에 작성한다. | 거치대를 단단히 고정한다. |
| 케이스 | PETG 3D 프린트 + 금속 클램프 | 야외 내열성과 내구성. | IMU는 케이스 바닥에 나사로 직접 고정한다. |

## 2. 레퍼런스 부품과 비교

레퍼런스(RoadQuality GPSTracker)와 부품이 달라 그대로 따라 할 수 있는지 검토했다.

| 부품 | 레퍼런스 | 우리 | 그대로 따라 할 수 있나 |
|---|---|---|---|
| MCU | ESP32 | ESP32-S3 | 거의 가능. 핀 번호만 바뀜 |
| IMU | MPU6050 (I2C) | ICM-42688-P (SPI) | 코드를 바꿔야 함. 연결 방식과 라이브러리가 다름 |
| GPS | NEO-6M 계열 | u-blox M10 | 거의 가능. 같은 UART 방식이고 10Hz 설정만 추가 |
| microSD | SD 모듈 | SD 모듈 | 그대로 가능 |
| 전원 | 18650 쉴드 | 18650 쉴드 | 그대로 가능 |

**결론:** 구조는 그대로 따르고, 부품이 다른 부분만 코드를 바꾼다. 처음에는 저렴한 레퍼런스 부품(MPU6050, NEO 계열)으로 레퍼런스를 그대로 따라 만들고, 동작하면 업그레이드 부품으로 하나씩 교체하는 방식을 택했다. 교체 전후 데이터 비교는 업그레이드의 근거가 된다.

## 3. GPS 모듈 조사

| 부품 | 세대 | 특징 |
|---|---|---|
| NEO-6M | 6세대 | 가장 오래됨, 가장 저렴, 레퍼런스에서 사용 |
| NEO-7M | 7세대 | 6M보다 조금 나음 |
| NEO-M8N | 8세대 | 여러 종류 위성을 동시에 잡아 정확함 |
| M10 계열 (SAM-M10Q, MAX-M10S) | 10세대 | 최신, 저전력, 감도가 좋음 |

**구매 시 확인한 점**

- **SAM-M10Q-00B 단품은 쓸 수 없다.** 기판에 직접 납땜하는 실장용(Surface Mount, 20-SMD) 부품이라 핀이 없어 브레드보드에 꽂을 수 없다.
- **같은 칩을 보드에 올린 브레이크아웃 모듈을 사야 한다.** 예: SparkFun GPS Breakout SAM-M10Q (GPS-21834). 핀 구멍에 핀 헤더만 납땜하면 된다.
- 국내 재고가 부족하고 가격이 높아, 팀원이 사용해 본 NEO 계열 모듈로 먼저 진행하고 이후 교체를 검토한다.

## 6. 택트 스위치의 용도

주행 중 요철을 지날 때 눌러 기록에 정답 표시(라벨)를 남기는 용도로 구매했다. 이후 주행 안전을 위해 **사후 라벨링**(주행 후 영상과 기록을 맞춰 표시)을 기본으로 바꾸고, 택트 스위치는 대안으로만 남겼다.
