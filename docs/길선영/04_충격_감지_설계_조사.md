# 04. 충격 감지 설계 조사

작성: 길선영 · 2026-10-24

단말(IMU·GPS)로 노면 충격을 감지하기 위해 조사한 기본 파이프라인, 장착 방법, 데이터 수집과 평가 방법을 정리한다.

## 1. 기본 파이프라인

1. **시간 동기화:** IMU 샘플과 GPS 위치·속도에 타임스탬프를 기록한다.
2. **전처리:** 고역통과 필터로 중력 성분과 저주파 차체 기울기를 줄인다. 차단 주파수는 스펙트럼을 본 뒤 정한다.
3. **주기 진동 확인:** 바퀴 회전 주파수는 속도를 바퀴 둘레로 나눠 계산한다(예: 둘레 0.68m, 시속 20km면 약 8Hz). 스펙트럼에서 확인된 경우에만 노치 또는 대역 필터를 적용한다.
4. **이벤트 검출:** 피크 임계값으로 후보 구간을 뽑고 앞뒤 구간을 함께 저장한다. 임계값은 학습 데이터에서 정하고 별도 평가 데이터로 검증한다.
5. **속도 보정:** 같은 요철을 여러 속도로 반복 주행해 속도와 충격 특징의 관계를 분석한다. 보정 전후 편차가 실제로 줄 때만 적용한다.
6. **특징 추출:** 최대값, RMS, 지속 시간, 축별 비율, 첨도, 자이로 피치 최대값 등을 계산한다.
7. **분류:** 정상 대 위험 이진 분류로 시작한다. 데이터가 충분하면 포트홀·방지턱 등으로 세분화하고 규칙 기반과 랜덤포레스트를 비교한다.
8. **위치 보정:** GPS 지연의 방향과 크기를 확인한 뒤 적용하고, 보정 전후 위치 오차를 비교한다.
9. **중복 제거:** DBSCAN으로 같은 지점의 이벤트를 묶고, 반복 검출 횟수와 이벤트 품질로 신뢰도를 계산한다.

## 2. 장착 방법

- IMU는 케이스 바닥에 나사로 단단히 고정해 장착 상태에 따른 신호 변화를 줄인다.
- 완충재는 케이스와 자전거 프레임 사이에만 쓰고, IMU 아래에는 부드러운 완충재를 넣지 않는다.
- 장착 위치 후보를 2~3곳(중간 프레임 등) 비교하고, 모든 주행에서 위치와 방향을 동일하게 유지·기록한다.
- GPS 안테나는 하늘이 잘 보이는 케이스 상단에 두고, 전원 변환부와 멀리 둔다.

## 3. 데이터 수집 계획

- **구간:** 허용된 장소에서 정상 노면 구간과 요철 구간(방지턱, 맨홀, 단차 등 안전하게 통과 가능한 것) 1~2곳을 정한다.
- **반복:** 같은 구간을 속도 3단계(저·중·고) × 각 5회 이상 달린다.
- **라벨링:** 주행 영상과 로그 시간을 동기화해 주행 후에 작성한다(사후 라벨링).
- **분리:** 학습 데이터와 평가 데이터는 주행 회차나 경로 기준으로 나눠, 같은 구간이 양쪽에 섞이지 않게 한다.
- **클래스:** 1차는 정상 대 위험으로 시작한다. 실제 포트홀은 드물어 클래스별 F1이 불안정할 수 있다.
- **기록 항목:** 장착 위치·방향, 날씨, 타이어 공기압, 탑승자.

**사후 라벨링의 부담:** 처음에는 요철이 있는 짧은 코스를 2~3번 반복 주행하고, 지나간 요철 10~20개 정도만 표시해도 기준값을 잡기에 충분하다.

## 4. 평가 지표

- 분류 성능: F1 score (클래스별과 macro-F1)
- 위치 오차(m): 실제 요철 위치와 지도 표시 위치 사이 거리
- 같은 경로 반복 주행 시 재검출률, 중복 제거 전후 이벤트 수·정확도
- 속도 보정 효과: 같은 요철을 여러 속도로 통과했을 때 충격 특징의 편차를 보정 전후 비교
- 데이터 누락률, 타임스탬프 간격, 연속 기록 시간

실제 주행 데이터로 평가한다. 합성 데이터는 파이프라인 시험용으로만 쓰고 성능 결과로 보고하지 않는다.

## 5. 위험 요소와 대응

| 위험 | 대응 |
|---|---|
| GPS 갱신률이 설정에 따라 낮아짐 | 설정별 기록률과 위치 오차를 비교하고 시간 동기화로 보정 효과 확인 |
| IMU ±16g 포화 | 포화 빈도와 파형을 확인하고, 반복 포화 시 고범위 가속도계(ADXL375) 검토 |
| SD 기록 중 데이터 누락 | 링버퍼와 블록 단위 저장, 타임스탬프 간격과 파일 무결성으로 검증 |
| 전원 강하 또는 리셋 | 센서·SD 동작 중 전압과 전류를 측정하고 전원 모듈·디커플링 보완 |
| 해외 구매품 배송 지연 | 가장 먼저 주문하고 구매처·증빙 요건 사전 확인 |

## 6. 안전

주행 시험은 허용된 장소에서 진행하고, 주행 중에는 버튼과 화면을 조작하지 않는다. 매 주행 전에 케이스 고정, 배터리 상태, 배선과 센서 이탈 여부를 점검하고 헬멧을 착용한다.
