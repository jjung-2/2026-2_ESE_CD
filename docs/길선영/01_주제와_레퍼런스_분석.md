# 01. 주제와 레퍼런스 분석

작성: 길선영 · 2026-10-29

## 1. 주제

자전거 프레임에 단 IMU로 포트홀과 요철 충격을 감지하고, GPS 좌표와 함께 서버로 보내 **위험 노면 지도**를 만드는 장치와 서비스.

**전체 구조**

```text
단말(ESP32-S3 + IMU + GPS) → 스마트폰(근처 위험 경고) → 서버(중복 제거, 신뢰도·심각도) → 지도 웹(심각도별 색상)
```

**분류 대상:** 정상, 과속방지턱, 포트홀, 보도블록 들뜸, 연석

## 4. 레퍼런스를 보며 찾은 검토 사항

1. **주기 진동 제거에는 회전수 정보가 필요하다.** 바퀴에 단 홀센서는 속도만 알려 주고 페달 회전수는 알려 주지 않는다. 크랭크 센서를 추가하거나, IMU 스펙트럼에서 주파수를 추정하는 방법을 정해야 한다.
2. **GPS 지연 보정의 차별성 확인이 필요하다.** Pothole Patrol도 위치 클러스터링을 했으므로, 단순한 "지연 × 속도" 보정만으로는 기여가 약할 수 있다.
3. **라이선스를 확인해야 한다.** RoadQuality(MIT), SimRa(Apache-2.0)는 코드 활용 부담이 적다. radweganalyse는 GPL-3.0이라 코드를 직접 섞으면 우리 코드도 GPL로 공개해야 한다.
4. **데이터 라벨링이 일정의 병목이다.** 클래스가 5개라 클래스별 샘플이 충분해야 하므로 수집 기간을 넉넉히 잡는다.

## 5. NAU Instrumented Bike와 비교

| 구분 | NAU Instrumented Bike | Safe Bike(Sabi) | 본 프로젝트 |
|---|---|---|---|
| 하드웨어 | Arduino Nano, 3축 가속도계, GPS, HC-06, OpenLog, 부저 | Jetson Nano, 카메라, 거리 센서 | ESP32-S3, 6축 IMU, GPS, microSD, 스마트폰 카메라 |
| 판정 방식 | 고정 임계값 (1.3~1.5G 보통, 1.5G 초과 심각) | 센서와 영상에 가중치 (알고리즘 미확립) | 필터, 이벤트 검출, 특징 기반 분류 |
| 중복 처리 | 같은 위치에서 5회 미검출 시 삭제 | 없음 | 공간 군집화(DBSCAN)와 반복 검출 기반 신뢰도 |
| 검증 | 캠퍼스 주행 테스트 | 설계 제안 단계 | 반복 주행 데이터로 정량 평가 |

**차별성의 범위:** 속도 보정과 군집화 개념은 선행 연구에 이미 있다. 본 프로젝트의 기여는 새 알고리즘 제안이 아니라, 선행 연구의 개념을 저가 오픈 하드웨어(ESP32)로 구현하고 실측으로 검증하며, 스마트폰 카메라와 결합해 실시간 알림 서비스로 연결하는 데 둔다.
